# دليل التعديل
- بيانات المركز: `src/config/site.ts`
- القائمة: `src/config/navigation.ts`
- التواصل الاجتماعي: `src/config/social.ts`
- الخريطة: `src/config/location.ts`
- محتوى الرئيسية: `src/data/home.ts`
- الشعار: `public/brand/logo.svg`
- الصور: `public/images/`
- الألوان: `src/styles/tokens.css`

## التشغيل
```bash
npm install
npm run validate
npm run dev
```
